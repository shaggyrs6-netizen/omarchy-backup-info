Omarchy Backups

A personal desktop backup setup using Rclone and Restic with Google Drive. This OAuth application is operated solely for its owner's use and is not offered as a public backup service.

Its only requested Google permission is drive.file: access to files created by, or specifically authorised for, this application. It does not request access to the owner's entire Drive.

Backup uploads are intended to contain locally encrypted Restic data. At present, only the Google connection has been tested; no backup uploads or schedules have been activated.
