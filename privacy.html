Omarchy Backups — privacy information

Last updated: 8 November 2026

Purpose: personal desktop backup and recovery using Google Drive.

Google data access: this application requests only https://www.googleapis.com/auth/drive.file. This permits creating and managing files associated with this application, including reading, updating and deleting those files. It does not request unrestricted access to existing Drive files. It may read account storage quota to check available backup capacity.

Local credentials: OAuth client credentials and access/refresh tokens are stored on the owner's computer in a configuration file restricted to that owner. Credentials are not included in this public website.

Backup data: the planned backup workflow encrypts selected data locally with Restic before transmitting it to Google Drive. Backup files remain in the owner's Google account until the owner or an explicitly authorised retention process removes them. No backup uploads or automated retention have been activated at the date above.

Sharing: this application does not sell data or use it for advertising or model training. Google processes information needed to provide OAuth and Drive services under its own policies. This informational website does not receive backup data or OAuth tokens and uses no site-authored analytics or forms. GitHub Pages may process ordinary access logs under GitHub's policies.

Control: the owner can revoke this application's access through Google Account security settings and separately delete its Drive files. Revoking access alone does not delete existing backups. Loss of access or encryption passwords can prevent recovery.

This application is for its owner's personal use; support is through the owner contact displayed on Google's consent screen.
